# data/

No imagery lives here, and none should. The notebook queries open archives at run
time — that is what makes the result reproducible from anywhere instead of only from
our copy of the pixels, and it is what keeps restricted data out of a public repo.

- `sample_input/` — the inputs one run actually used, and a small offline sample you
  can score in a second. Read `sample_input/README.md` first.

Outputs go to `results/`, not here.
