What we ship

Three things, each one usable on its own

Dashboard

Map of every detected pivot, the ranked inspection queue, each field's own NDVI history with its cuts marked, and a side-by-side against the naive decline ranking.

API

A read-only service — /priority, /fields/{id}, /comparison — so the ranking feeds a farm's existing software instead of demanding a new system.

Notebook

One notebook rebuilds every number in the submission from open archives, and writes the data files the dashboard and API read. A verification suite runs the whole thing offline and holds the API and the interface to identical output.

No proprietary data, no supplier who can change terms, no credentials in the repository. Sentinel-2 and EMIT are openly licensed and the analysis code is ours.

The API is the integration path: most farms already have software; none of it models the cutting cycle.

Emphasise deployability — this is the criterion that rewards a working interface over four matplotlib panels. The API framing matters commercially: we do not have to displace an incumbent to be useful.
