Detection is a shape test

NDVI above 0.30, then keep only what is shaped like a pivot: 10–400 ha, eccentricity at most 0.75, solidity at least 0.85. No boundaries were supplied and none were drawn by hand.

Detect at peak green

The date is chosen automatically: the greenest fully covered day of the season. This run chose 13 April and found 518 fields. An earlier run over the same area detected in July instead and found only 328, because fields that were mid-cut that day fell below the threshold.

Sentinel-2 L2A, cloud < 20%, mosaicked by solar day, SCL classes 0/1/3/8/9/10/11 removed. 20 m for detection, 60 m for the series.

The 518-versus-328 difference is worth pausing on: it is the same confound appearing in the detection step, and it is why the detection date is chosen by the algorithm rather than by us.
