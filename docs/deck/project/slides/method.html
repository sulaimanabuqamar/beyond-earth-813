The tool

Judge every field against its own rhythm, not against its neighbours

01

Find the cuts

A peak counts only if it stands 0.20 NDVI above the low points on both sides. That prominence test separates a real cut from a cloudy pixel.

02

Measure its cycle

Median spacing between that field's peaks, bounded to 18–60 days. Fewer than two clean peaks and we say so rather than invent one.

03

Expect a value

What did this field read this many days after each of its previous cuts? A low-vigour field is judged against itself.

04

Rank the deficit

Priority = how far behind its own history, times hectares. Exactly zero when a field is on schedule.

Because priority is zero for a field that is on schedule, a freshly cut field can never enter the queue. That is the entire design.

Runs on free Sentinel-2. No hyperspectral data required.

Four steps, and the fourth is the one that matters. Land the last line: the tool is built so that the failure mode on slide four is structurally impossible, not merely less likely.
